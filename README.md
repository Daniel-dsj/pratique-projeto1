# Calculadora em Python

Projeto simples de calculadora desenvolvido em Python.

## Funcionalidades

- Soma
- Subtração
- Divisão
- Multiplicação

## Como executar

Primeiro dê permissão ao arquivo:

chmod +x calculadora.sh

Depois execute:

./calculadora.sh

## Tecnologias utilizadas

- Python 3
- Shell Script (.sh)
